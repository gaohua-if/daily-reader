## 摘要

Alook 把本地编程 Agent 接入团队共享频道，Code Mode 用脚本组合工具调用，Claude Code 团队的验证文章讲如何给修改建立可检查的完成标准。三份资料分别涉及协作入口、执行方式和结果验证。

## 逐条笔记

### 1. alookai/alook

Alook 为本机运行的编程 Agent 提供持续身份、收件箱和频道成员关系。人和 Agent 可以在共享频道、群组及私聊中共同工作，支持接入 Claude Code、Codex、Cursor 等运行时。项目提供本地连接与启动流程，适合了解如何让团队访问已有的个人 Agent。[项目 README](https://github.com/alookai/alook)

### 2. Claude Code 的 Code Mode

Claude 生成 JavaScript，在一次执行中串联或并行调用工具，并把需要的输出交回模型。适合跨文件批量修改、搜索后过滤和多个独立检查。官方文档将其标为默认关闭的实验功能。原有摘要见 11 月 16 日笔记。[官方文档](https://code.claude.com/docs/en/code-mode) · [首次收录笔记](2026-11-16.md#4-claude-code-的-code-mode)

### 3. How the Claude Code team thinks about verification

Addy Osmani 于 2026 年 11 月 16 日发表的工程文章。端到端测试检查完整用户流程，属性测试用生成输入检查不变量，差分测试比较新旧系统处理相同输入的结果。团队把启动并检查真实应用的步骤写进验证技能，对代码变更匹配相关的可靠性检查，并从历史故障和回滚案例评估审查效果。文章还介绍了从基础分支读取审查规则、针对固定提交验证，以及先观察新门禁的误判再启用阻断的做法。[原文](https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/)
