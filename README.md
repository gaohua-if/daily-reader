## 值得读

### 2026-11-18 · Agent 协作与验证

1. **How the Claude Code team thinks about verification**。适合给编程 Agent 设计验收流程时阅读。重点看三类测试的用途，以及如何用真实故障评估验证规则。[Claude 开发者博客](https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/)

### 2026-11-16 · Agent 工程

1. **Building always-on agents**。如果只读一篇，选这篇。它讲清楚事件如何唤醒 Agent、运行如何恢复，以及什么时候需要人工确认。[Anthropic 指南](https://claude.com/resources/articles/building-always-on-agents)
2. **Introducing Context Repositories**。了解如何用 Git 管理跨会话记忆，以及怎样决定哪些记忆常驻、哪些按需加载。[Letta 原文](https://www.letta.com/blog/context-repositories/)
3. **Worse Together**。适合设计多人共用预算、日程或合并队列时阅读，重点看共享预算和团体点餐实验中分别奏效的协调方式。[乔木中文解读](https://blog.qiaomu.ai/worse-together-multi-agent) · [研究团队原文](https://alignment.anthropic.com/2026/worse-together/)
4. **Siboot 的多 Agent 协作实践**。适合设计团队群里的 Agent 接力流程。重点看如何用 Topic 聚合同一任务的讨论、文件和进度，让接手的人或 Agent 直接查阅。[公众号原文](https://mp.weixin.qq.com/s/L7WgswCBgMGUF7mD7pcYfw)
